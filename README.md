# graf-appColorGithub-
La aplicación web desarrollada es un ** controlador de iluminación RGB para una computadora ** , diseñado para permitir al usuario seleccionar y personalizar el color de los componentes de una PC de manera interactiva.

La aplicación cuenta con un ** selector de color HTML ** , controles deslizantes y campos numéricos para modificar los valores de ** rojo (R), verde (G) y azul (B) ** en un rango de 0 a 255. A partir de estos valores, el sistema muestra automáticamente el ** código RGB y su equivalente hexadecimal ** .

Como elemento visual principal, se representa una computadora con diferentes componentes, entre ellos la ** memoria RAM, el disipador del procesador, la tarjeta gráfica y los ventiladores ** . Al seleccionar un color, la iluminación RGB de todos estos componentes se actualiza de manera simultánea, creando un efecto de iluminación coordinada similar al que utilizan algunas computadoras gaming.

La aplicación fue desarrollada utilizando ** HTML para la estructura ** , ** CSS para el diseño y los efectos visuales ** , ** JavaScript para la interacción y conversión de colores ** , y ** Bootstrap para facilitar la creación de una interfaz moderna y adaptable a diferentes tamaños de pantalla ** .

De esta manera, la aplicación combina conceptos de diseño web, programación e interacción con el usuario para crear un sencillo simulador de control de iluminación RGB para una computadora.
